# c++ note


## 常量指针和指针常量
```c++
int a = 10, b = 20;
const int* p = &a; //常量指针（const pointer to data）
```
数据是常量，不能通过该指针修改数据，但指针本身可以指向其他地址。

```c++
int a = 10, b = 20;
int* const p = &a; //指针常量（pointer to const）
```
指针本身是常量，一旦初始化后就不能再指向其他地址，但可以通过该指针修改指向的数据（如果数据本身不是常量）。


**总而言之 \*「左定值，右定向」**  

  


## 引用

**引用的本质在c++内部实现是一个指针常量.**




## this

this 与 *this 的关系：  

this 是一个隐含的常量指针（T* const this，其中 T 是类类型），指向当前对象的内存地址。  

对 this 指针解引用（*this），就得到了指针所指向的对象本身。


## 空指针（Null Pointer） 
 是一个特殊的指针值，表示该指针不指向任何有效的内存地址。它主要用于表示 “指针未指向任何对象” 的状态，避免野指针（指向无效内存的指针）导致的不可预期错误。

典型用途

（1）初始化指针，避免野指针

（2）作为函数返回值，表示 “无有效结果”

```C++
int* find(int* arr, int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target) {
            return &arr[i]; // 找到目标，返回地址
        }
    }
    return nullptr; // 未找到，返回空指针
}
```

（3）作为条件判断，检查指针有效性

```C++
int* p = getSomePointer(); // 假设此函数可能返回空指针
if (p != nullptr) { // 检查指针有效
    *p = 100;       // 安全操作
} else {
    cout << "指针为空，无法操作" << endl;
}
```


（4）释放动态内存后，将指针置空
使用 delete 释放动态内存后，指针不会自动变为空，需手动置空，避免再次访问已释放的内存（悬空指针）
```C++
int* p = new int(10);
delete p;   // 释放内存
p = nullptr; // 置为空，避免成为悬空指针
```

```cpp
#include <iostream>
using namespace std;

// 1. 全局区（数据段/BSS段）：存放全局变量、静态全局变量
int global_var = 10; // 全局变量（已初始化，存放在数据段）
int global_uninit;   // 全局变量（未初始化，存放在BSS段）
static int static_global = 20; // 静态全局变量（已初始化，数据段）


// 3. 代码区：存放函数的二进制指令（所有函数的实现都在这里）
void test_func(int param) { // param是函数参数，存放在栈区
    // 2. 全局区：静态局部变量（虽在函数内，但属于全局区）
    static int static_local = 30; // 静态局部变量（数据段）
    
    // 4. 栈区：局部变量（函数内定义的非静态变量）
    int local_var = 40; // 局部变量（栈区）
    
    // 打印各变量地址，辅助观察（地址值仅作参考，不代表绝对规律）
    cout << "test_func内：" << endl;
    cout << "  函数参数param（栈区）：" << &param << endl;
    cout << "  静态局部变量static_local（全局区）：" << &static_local << endl;
    cout << "  局部变量local_var（栈区）：" << &local_var << endl;
}


int main() {
    // 2. 全局区：字符串常量（存放在全局区的只读数据段）
    const char* str_const = "hello world"; // 字符串常量本身在全局区，指针str_const在栈区
    
    // 4. 栈区：main函数的局部变量和参数
    int main_local = 50; // 局部变量（栈区）
    
    // 5. 堆区：动态分配的内存（通过new/malloc分配）
    int* heap_ptr = new int(60); // 动态分配的int（堆区），指针heap_ptr在栈区
    
    // 打印各部分地址，观察内存分布规律
    cout << "全局区：" << endl;
    cout << "  全局变量global_var（数据段）：" << &global_var << endl;
    cout << "  未初始化全局变量global_uninit（BSS段）：" << &global_uninit << endl;
    cout << "  静态全局变量static_global（数据段）：" << &static_global << endl;
    cout << "  字符串常量\"hello world\"（全局区只读段）：" << (void*)str_const << endl; // 注意强转void*
    
    cout << "\n栈区：" << endl;
    cout << "  main函数局部变量main_local（栈区）：" << &main_local << endl;
    cout << "  指向堆的指针heap_ptr（栈区，本身是局部变量）：" << &heap_ptr << endl;
    
    cout << "\n堆区：" << endl;
    cout << "  new分配的int（堆区）：" << heap_ptr << endl;
    
    cout << "\n调用test_func观察其内部变量：" << endl;
    test_func(100); // 实参100会被复制到形参param（栈区）
    
    // 释放堆区内存（必须手动释放，否则内存泄漏）
    delete heap_ptr;
    return 0;
}
```


### 各区域对应代码部分说明：
1. **代码区**  
   所有函数的实现（二进制指令）都存放在这里，包括`main`函数、`test_func`函数，以及`cout`等库函数的底层实现。代码中无法直接打印代码区的地址，但函数的调用逻辑依赖于代码区的指令。


2. **全局区**  
   代码中以下部分存放在全局区：  
   - 全局变量：`global_var`（已初始化，数据段）、`global_uninit`（未初始化，BSS段）。  
   - 静态全局变量：`static_global`（静态变量无论是否在函数外，都属于全局区）。  
   - 静态局部变量：`test_func`内的`static_local`（虽在函数内，但生命周期与程序一致，存放在全局区）。  
   - 字符串常量：`"hello world"`（存放在全局区的只读数据段，不可修改）。  


3. **栈区**  
   代码中以下部分存放在栈区：  
   - 函数参数：`test_func`的`param`（函数调用时分配，调用结束释放）。  
   - 局部变量（非静态）：`test_func`内的`local_var`、`main`内的`main_local`，以及指针`heap_ptr`（指针本身是局部变量，存放在栈区，指向堆区数据）。  


4. **堆区**  
   代码中通过`new`动态分配的内存存放在堆区：`new int(60)`分配的int类型数据，地址由`heap_ptr`指向。堆区内存必须通过`delete`手动释放（否则会导致内存泄漏）。


### 运行观察建议：
编译运行后，会打印各部分的内存地址。观察地址值可发现：  
- 全局区变量的地址通常较为接近（且低于堆区和栈区）。  
- 栈区变量的地址通常较高（且堆区地址一般低于栈区，因堆向上增长、栈向下增长）。  
- 堆区地址与栈区地址有明显差距（中间隔有空闲内存）。  

通过地址分布可直观感受内存四区的布局差异。


内存四区中的“堆”和“栈”，与算法中的“堆”和“栈”是完全不同的概念，分别属于计算机内存管理和数据结构两个领域。以下是具体区别：


### 一、内存四区中的“堆”和“栈”（内存管理概念）
指程序运行时内存的两种分配区域，用于存储数据，由操作系统或编译器自动/手动管理。

| 特性         | 内存中的“栈”（Stack）                          | 内存中的“堆”（Heap）                            |
|--------------|------------------------------------------------|------------------------------------------------|
| **分配方式** | 自动分配/释放：由编译器自动管理，函数调用时分配，函数结束时释放。 | 手动分配/释放：由程序员通过 `new/malloc` 分配，`delete/free` 释放（C/C++）。 |
| **存储内容** | 函数参数、局部变量、返回地址等。                | 动态分配的变量、对象（如 `new int` 创建的数组）。 |
| **大小限制** | 通常较小（如几MB），由系统预先设定。            | 较大（如几GB），受限于系统内存总量。            |
| **生长方向** | 向下生长（从高地址到低地址）。                  | 向上生长（从低地址到高地址）。                  |
| **效率**     | 高（直接通过栈指针操作，无碎片）。              | 低（需要查找空闲内存块，可能产生碎片）。        |
| **安全性**   | 自动释放，不易内存泄漏，但可能栈溢出（如递归过深）。 | 需手动释放，易内存泄漏或double free错误。       |


### 二、算法中的“堆”和“栈”（数据结构概念）
指两种特定的抽象数据结构，用于组织数据，关注数据的存储和操作规则。

| 特性         | 数据结构中的“栈”（Stack）                      | 数据结构中的“堆”（Heap）                        |
|--------------|------------------------------------------------|------------------------------------------------|
| **定义**     | 一种“后进先出”（LIFO）的线性结构，仅允许在一端（栈顶）操作。 | 一种完全二叉树结构，分为“大根堆”（父节点≥子节点）和“小根堆”（父节点≤子节点）。 |
| **核心操作** | `push`（入栈）、`pop`（出栈）、`top`（取栈顶）。 | `insert`（插入）、`extract-min/max`（提取最小/大值）、`heapify`（堆化）。 |
| **应用场景** | 函数调用栈、表达式求值、括号匹配等。            | 优先队列、堆排序、Top-K问题等。                |
| **实现方式** | 可通过数组或链表实现。                          | 通常通过数组实现（利用完全二叉树的索引特性）。  |
| **与内存的关系** | 数据结构的“栈”可以用内存的“栈”或“堆”存储（如C++中 `std::stack` 可动态分配内存）。 | 数据结构的“堆”同样可存储在内存的“栈”或“堆”中（如 `std::priority_queue` 可能使用动态内存）。 |


### 三、关键区别总结
1. **本质不同**：  
   - 内存中的“堆/栈”是**物理内存区域**，用于存储程序运行时的数据，管理内存分配。  
   - 算法中的“堆/栈”是**逻辑数据结构**，用于组织数据的访问顺序和规则，与物理内存无关。

2. **命名巧合**：  
   两者名称相同是历史原因，没有直接关联。例如：  
   - 内存的“栈”得名于其“先进后出”的内存分配方式，与数据结构的“栈”行为一致，但本质是内存区域。  
   - 内存的“堆”得名于其内存块的“散乱分布”特性，而数据结构的“堆”是二叉树结构，两者毫无关系。
∏
3. **关联场景**：  
   数据结构的“栈”或“堆”在程序中实现时，其底层存储可能用到内存的“栈”（如局部数组实现的栈）或内存的“堆”（如动态分配的堆结构），但这是“实现细节”，而非概念本身。


举例说明：  
- 用 `int stack[10]` 实现一个数据结构的栈，其存储在内存的“栈”中（局部变量）。  
- 用 `new int[10]` 实现一个数据结构的栈，其存储在内存的“堆”中（动态分配）。  
- 无论存储在哪里，这个结构的“后进先出”特性（数据结构的栈）不变。

#一个简单的随记器数组写法
#include<bits/stdc++.h>
using namespace std;
vector<int> random_arry(int n,int min_num,int max_num){
  srand(time(0));
  vector<int> arr(n);
  for(int i=0;i<n;i++){
    arr[i]=min_num+rand()%(max_num-min_num+1);
  }
  return arr;
}
int main(){
  for(auto i:random_arry(10,0,10)){
    cout<<i<<' ';
  }
}
